# newAPIshare 产品心智模型

## 数据源分层

1. `public/sites.xlsx` 是唯一业务数据与表格格式来源。第一张工作表是网页主数据表，其他工作表必须保留。
2. `columns.json` 保存字段元数据：字段顺序、显示/隐藏、私列、类型等。
3. `buttons.json` 保存按钮默认配置和单元格覆盖。
4. CSV 只作为备份导出和旧数据迁移输入，不参与日常编辑链路。

## 编辑链路

- 单元格、样式、行高、列宽、行列顺序等用户操作均形成可序列化快照事务。
- 撤销/重做恢复完整快照，而不是只恢复文字。
- 点击保存后，同步助手采用临时文件 + 原子替换写回 XLSX，并保留其他工作表。
- 自动推送只针对当前功能分支，不直接改写远程 `main`。

## 交互边界

- `/edit` 页面阻止浏览器原生右键，自定义菜单通过 Portal 展示，按视口边界自动定位，过高可滚动。
- 行头拖拽只在未排序、未筛选的原始顺序下启用，使用 `uid` 作为稳定身份。
- 浏览态只渲染公开列，并显示 Excel 保存的公开单元格样式。
- 暂不提供单元格内部文本域/按钮的低代码自由拖放排版；当前使用稳定的表格单元格文本与按钮布局。

## 验收口径

- 重新加载后数据、样式、行高、列宽和行顺序保持。
- 其他工作表不被覆盖。
- 缺失或损坏 XLSX 给出明确错误。
- 排序/筛选时拖拽被拒绝并提示用户。
