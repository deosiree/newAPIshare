## ⚠️ 一次性迁移:把 Pages 构建设置改成 React 模式(现在就要做)

仓库已从「根目录静态 HTML」升级为「React 构建」,你现有的 Pages 项目需要改两个框,否则线上会白屏:

1. Cloudflare 后台 → Workers 和 Pages → 你的项目 → **设置(Settings) → 构建(Builds & deployments) → 编辑构建配置**
2. 改成:
   - **构建命令(Framework preset 可选 Vite,或自定义)**:`npm run build`
   - **构建输出目录**:`dist`
3. 同页 → **环境变量(Environment variables)** 添加(生产+预览都要):
   - `NODE_VERSION` = `20`
   - `VITE_EDIT_KEY` = `cbe72d15-48f1-4ef1-a214-6283d2d140be`(就是 .env 里的编辑密钥;建议换成你自己新生成的)
4. 保存后点 **部署(Deployments) → 重试部署/Retry**,1 分钟后线上恢复

> 验证:打开网址应看到表格;`网址/?k=密钥` 出现「私人视图」徽章;`网址/edit` 出现编辑态表格。

## 一、日常更新(部署完成后,改数据的三种方式)

### 方式 1:GitHub 网页改 CSV(手机也行)

1. `github.com/deosiree/newAPIshare` → **public/sites.csv** → 铅笔图标
2. CSV 是纯文本:改文字/加行(复制一行)/加列(加一列文字)都像改表格
3. **Commit changes** → 自动构建,约 1-2 分钟线上生效

### 方式 2:在线编辑态(推荐,像 Excel 一样)

1. 双击 `tools\启动同步工具.bat`(本机,保持窗口开着)
2. 打开 `网址/?k=密钥` → 点页脚 **「编辑态 →」**(或直接 `网址/edit`)
3. 表格直接改单元格;工具栏支持:**保存 / 撤销 / 重做 / 导入Excel / 导出Excel / 超链接 / ±行 / ±列 / 居中 / 靠左 / 状态·评分快速过滤 / 显示隐藏列 / 同步 New API**
4. **右键**任意单元格:隐藏此列(浏览态消失)/隐藏此行/删除行列
5. 改完点 **💾 保存** → 自动写回 CSV 并 push → 约 1 分钟线上生效
6. 「同步 New API」按钮 = 检测渠道 → 预览(旧值→新值)→ 勾选确认写入

### 方式 3:本地 Excel 工作流

- 直接用 Excel 打开 `public/sites.csv` 编辑保存 → `git add -A && git commit -m "update" && git push`
- 或把旧 Excel 批量导入:`python excel2data.py docs/xxx.xlsx`
- 重爬三源评价:`python tools/crawl_reviews.py`;重提签到地址:`python tools/import_checkin.py`

## 二、更新如何生效

```
git push(或网页 Commit / 编辑态保存)
   ↓ 自动触发
Cloudflare Pages:npm ci → npm run build(约 1-2 分钟)
   ↓
dist 上线,全球 CDN 同步
```

- 看进度:项目 → **部署** 标签,每条对应一次部署
- 验证:页头「数据更新于」日期;手机看到旧内容 = 浏览器缓存,强刷即可

## 三、回滚

- **最快**:部署 标签 → 上一次成功的部署 → 菜单 → **回滚**(不碰代码)
- **git**: `git revert HEAD && git push`
- **CSV 改炸了**:GitHub 网页把 CSV 改回正确格式;或本地 `git checkout public/sites.csv` 后重新提交

## 五、排障 FAQ

| 症状 | 解法 |
|---|---|
| 线上白屏/404 | 构建设置没改(见最上方「一次性迁移」);或 Deployments 里看失败日志 |
| `workers.dev` 打不开 | 国内被墙,正常现象;用 Pages 的域名 |
| `pages.dev` 偶发慢 | 运营商波动;长期方案=绑自定义域名 |
| 编辑态进不去/私列不显示 | `?k=` 密钥与 Pages 环境变量 `VITE_EDIT_KEY` 不一致;先访问 `?k=off` 清状态 |
| 保存按钮报「同步助手未启动」 | 双击 `tools\启动同步工具.bat`;保存失败时可用「导出Excel」兜底,或 GitHub 网页改 CSV |
| 撤销按钮是灰的 | 没有可撤销的操作;编辑单元格/加删行列后才会亮 |
| 改列宽/拖列序没保存 | 改完要点「保存」,布局写进 columns.json |
