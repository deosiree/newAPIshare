# 部署与更新完整指南

> 本站 = 纯静态文件(`index.html` + `data.js`)托管在 Cloudflare Pages 上,仓库 `deosiree/newAPIshare` 为唯一数据源。
> 本文覆盖:首次部署 → 部署后修改代码 → 更新如何生效 → 回滚 → 自定义域名 → 排障。

---

## 一、首次部署（已完成,换电脑/重建时按此走）

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧 **构建 → 计算 → Workers 和 Pages**
3. 点右上角 **创建** → 标签切到 **Pages** → **连接 Git**
4. 授权 GitHub → 选仓库 `deosiree/newAPIshare`(私有仓库,授权时允许访问)
5. 构建设置:**预设 None、构建命令留空、输出目录 `/`** → 保存并部署
6. ~1 分钟后,项目**概览页顶部**就是你的网址:`https://<项目名>.pages.dev`

**我的部署信息(自己填上):**

| 项 | 值 |
|---|---|
| Pages 项目名 | `____________` |
| 正式网址 | `https://____________.pages.dev` |
| 私人视图 | `https://____________.pages.dev/?k=你的密钥` |

> ⚠️ 注意区分:Worker 的域名是 `xxx.你的账号名.workers.dev`,**在国内被墙,打不开是正常的**;
> Pages 的域名是 `项目名.pages.dev`。两者是不同产品,别混淆。

## 二、部署后如何修改代码（4 种方式,按场景选）

### 方式 1:GitHub 网页直接改(最常用,手机也行)

1. 打开 `github.com/deosiree/newAPIshare` → 点 **`data.js`**
2. 点右上角**铅笔图标**(编辑)
3. 直接改 JSON:每行一个站点 `{ }`,改文字、加行(复制一行 `{ }` 粘贴再改)、加列(在 `{ }` 里加 `"新字段": "值"`,网页会自动多出一列)
4. 拉到最上面点 **Commit changes**(提交)——改完立即生效,无需其他操作

> 注意别破坏 JSON 格式:引号、逗号要成对。改坏了看下面「回滚」。

### 方式 2:本机编辑器 + git(适合大改)

```bash
cd C:\Users\huiyan\Documents\Repertory\newAPIshare
# 用任何编辑器改 index.html / data.js
git add -A && git commit -m "更新说明" && git push
```

### 方式 3:网页工具面板同步 New API(每日运维)

1. 双击 `tools\启动同步工具.bat`(保持窗口开着)
2. 打开网站 → 加 `?k=密钥` 进私人视图 → 点 **「检测 New API 渠道」**
3. 弹窗里是**预览清单**(字段|旧值→新值),勾选要的 → **确认写入**
4. 自动改 `data.js` 并 push,约 1 分钟线上生效

### 方式 4:工具脚本批量重建(数据源大改)

```bash
python excel2data.py        # Excel → data.js
python tools/crawl_reviews.py   # 重爬三源评价 → 其他2/3/4
python tools/import_checkin.py  # 重提书签签到地址
git add -A && git commit -m "update" && git push
```

## 三、更新如何生效（Pages 自动构建）

```
git push(或 GitHub 网页 Commit)
   ↓ 自动触发
Cloudflare Pages 构建(纯静态,几秒)
   ↓
线上 ~1 分钟内生效,全球 CDN 同步
```

**查看构建进度**:Workers 和 Pages → 你的 Pages 项目 → **部署(Deployments)** 标签,每条记录对应一次部署,显示提交信息与状态(成功/构建中/失败)。

**验证更新生效**:

- 公开页:看页头的「数据更新于」日期(来自 data.js 的 `updated` 字段)
- 私人视图:加 `?k=密钥`,确认私列出现
- 手机上看到旧内容 → 是浏览器缓存,**下拉刷新或清缓存**即可(静态站无服务端缓存问题)

## 四、回滚（改坏了怎么办）

**方法 A(最快,不碰代码)**:项目 → **部署** 标签 → 找到上一次成功的部署 → 右侧菜单 → **回滚**。线上立即恢复到那个版本。

**方法 B(git 撤销提交)**:

```bash
git revert HEAD          # 撤销最近一次提交(生成一条反向提交)
git push
```

**方法 C(JSON 改炸了)**:直接回 GitHub 网页把 data.js 改回正确格式再 Commit;或本地 `git checkout data.js` 恢复后重新提交。

## 五、绑定自定义域名（国内访问优化,可选）

`pages.dev` 国内一般可访问,但偶有运营商波动。绑定自己的域名后走 Cloudflare 代理,最稳:

1. 弄一个域名:
   - **免费**:`eu.org`(nic.eu.org,审批数周)/ `us.kg`(DigitalPlat,需 KYC)/ `pp.ua`(需验证)——共同点:**每年记得续期**
   - **付费**:腾讯云/阿里云 `.top` 首年 ¥9-25、`.com` 约 ¥60/年,实名即可,**海外托管无需备案**
2. Pages 项目 → **自定义域(Custom domains)** → 设置自定义域 → 输入你的域名
3. 按提示在域名 DNS 处加一条 **CNAME → `<项目名>.pages.dev`**(若 DNS 托管在 Cloudflare 会自动加)
4. 等证书自动签发(几分钟),之后 `https://你的域名` 永久可用

## 六、排障 FAQ

| 症状 | 原因与解法 |
|---|---|
| `xxx.workers.dev` 打不开 | 该域名在国内被墙。不用它,用 Pages 的 `项目名.pages.dev` |
| `pages.dev` 手机偶尔慢/超时 | 运营商线路波动,换 Wi-Fi/流量试试;长期方案=绑自定义域名 |
| 改了 data.js 网站没变 | ① 看 Deployments 是否构建完成 ② 手机浏览器缓存,强刷 ③ 确认 push 成功 |
| `?k=密钥` 进不了私人视图 | 密钥和 `index.html` 顶部 `CONFIG.privateKey` 不一致;先访问 `?k=off` 清掉旧状态再试 |
| 私人视图工具面板红点 | 本机没跑同步助手:双击 `tools\启动同步工具.bat` |
| 部署构建失败 | Deployments → 点失败记录看日志;本仓库纯静态,一般不会失败,失败多半是 GitHub 授权过期,重新 Connect |
| 想换项目名/网址 | Pages 项目 Settings → 可改项目名(网址跟着变,旧名失效);或重建项目 |
