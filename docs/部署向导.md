# 部署向导（全程 0 元，约 10 分钟）

> 仓库已经建好并推送完毕(https://github.com/deosiree/newAPIshare),只差"把仓库接到 Cloudflare Pages"这一步。

## 第一步：Cloudflare Pages 连接仓库（必须,约 5 分钟）

1. 注册/登录 [dash.cloudflare.com](https://dash.cloudflare.com)(只需邮箱,免费)
2. **2026 新版后台入口**:左侧栏 **Build → Compute**(旧版的 Workers & Pages 已收进这里)
3. 进入 Compute 页面后点 **Create(创建应用)**
4. 创建弹窗顶部的标签里切到 **Pages** → 选 **Connect to Git**
5. 授权 GitHub → 选中仓库 `newAPIshare`(**注意:仓库是私有的,授权时允许访问私有仓库**)
6. 构建设置:
   - Framework preset: `None`
   - Build command: **留空**
   - Build output directory: **`/`**
7. **Save and Deploy** → 一分钟后项目页顶部就会显示 `https://xxxx.pages.dev` 形式的免费网址(域名随机后缀可在项目 Settings 里改)

> 说明:`xxx.pages.dev` 免费域名不是在页面上领取的,而是**创建 Pages 项目并完成首次部署后自动分配**。
> 如果 Create 弹窗里没有 Pages 标签(界面持续改版),把看到的选项截图发给助手,按实际界面调整指引。
> 以后每次 `git push`,网站 **自动重新发布,约 1 分钟生效**;改坏可在 Deployments 里一键回滚

> 为什么选 Cloudflare Pages:免费、送 HTTPS、支持私有仓库、`pages.dev` 域名国内一般可直接访问。

## 第二步（可选）：免费自定义域名

不想用 `pages.dev` 后缀的话,三个 0 元选项(都能绑到上面的 Pages 项目):

| 域名 | 申请 | 代价 |
|---|---|---|
| `你的名字.eu.org` | [nic.eu.org](https://nic.eu.org) 填表 | 人工审批,数周;**每年需手动续期** |
| `你的名字.us.kg` | DigitalPlat FreeDomain,需简单 KYC | 2025 年曾出续期风波;每年续期 |
| `你的名字.pp.ua` | nic.pp.ua,需身份验证 | 门槛略高 |

申请到后绑定:Pages 项目 → **Custom domains → Set up a custom domain** → 按提示在域名 DNS 里加一条 CNAME 指向 `xxx.pages.dev`(Cloudflare 托管 DNS 会自动加)→ 证书自动签发。

> ⚠️ 免费域名共同风险:忘记续期会被回收。建议把续期日期写进日历。

## 第三步（可选）：花钱买正式域名

想要短/好记/稳的:腾讯云/阿里云买 `.top`(首年 ¥9-25)或 `.com`(¥60/年),实名认证即可——**托管在 Cloudflare 海外,不需要 ICP 备案**。绑定方式同上。

## 第四步：改掉私人视图密钥

编辑 `index.html` 顶部:

```js
var CONFIG = {
  privateKey: 'huiyan829',   // ← 改成你自己的密钥
  ...
};
```

改完 commit+push,1 分钟生效。之后访问 `网址?k=新密钥` 解锁私人视图(私列+工具面板),`?k=off` 退出。

## 每日运维速查

- **改几条数据**:手机/电脑开 github.com → `data.js` → 铅笔 → 改 → Commit
- **同步 New API**:双击 `tools/启动同步工具.bat` → 网页点「检测 New API 渠道」→ 预览 → 确认写入
- **回滚**:仓库 Commits → 找到好的版本 → Revert
- **网站没更新?**:Cloudflare Deployments 看构建状态;或确认 git push 成功
